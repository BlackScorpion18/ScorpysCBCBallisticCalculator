# Scorpy's Create Big Cannons Ballistic Calculator

## What is SCBCBC?

**Scorpy's Create Big Cannons Ballistic Calculator** (or SCBCBC, if you want to avoid a mouthfull) is designed to aid with aiming big cannons from Create Big Cannons, an addon to the Create mod for Minecraft: Java Edition. 
<br>
It's a program that runs in the command line with the goal of computing firing solutions (a yaw angle and two pitch angles), given an input of the Minecraft coordinates for both the cannon and target, the powder charge level and cannon length.

## How to install

On the right side of the repo's page you'll be able to find an `.exe`, already ready to be ran in Windows.
<br>
If you're on another operating system, such as MacOS or a Linux distro, you can download the source code and compile it locally by using CMake and your C compiler of choice.

## How to run & use

Simply run the `.exe` file (or the file you compiled yourself, if you're not on Windows), and a command terminal will appear, running the program. On it, you can type `help` for a list of all available commands.
